## FAQ-бот для онлайн-школы «SkillUp»

Concept project для портфолио. Бот отвечает на типовые вопросы потенциальных студентов и заменяет менеджера по рутинным обращениям.

---

## Структура проекта

```
skillup-faq-bot/
├── bot.py             # точка входа, запуск бота
├── handlers/
│   ├── start.py       # команда /start
│   └── faq.py         # обработка кнопок меню
├── keyboards/
│   └── main_kb.py     # inline-клавиатура главного меню
├── data/
│   └── content.json   # все тексты ответов
├── .env               # токен бота (не коммитить)
├── .env.example       # шаблон переменных
├── requirements.txt
└── README.md
```

---

## Функционал

- Команда `/start` — приветствие + главное меню
- Команда `/help` — краткая справка
- Разделы меню (inline-кнопки):
  - О школе
  - Цены и оплата
  - Как проходит обучение
  - Сертификат
  - Частые вопросы
  - Написать менеджеру
- Кнопка «Назад» из любого раздела
- Все тексты в `content.json` — менять без правки кода

## Стек

| Инструмент | Назначение |
|---|---|
| Python 3.11 | язык |
| aiogram 3 | фреймворк для Telegram Bot API |
| python-dotenv | загрузка переменных из .env |
| Railway / VPS | хостинг |

## Установка и запуск

```bash
git clone <repo>
cd skillup-faq-bot
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# вставить токен в .env
python bot.py
```
